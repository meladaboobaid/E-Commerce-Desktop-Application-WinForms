# Sawa Store Desktop Application 🛒

> ⚠️ **Learning Project**
>
> This project is built for **learning and practice purposes only**.
> It is **not a full production-ready e-commerce system**.
> Some parts of the code are intentionally simple, and in several areas the implementation may **not fully follow enterprise-level best practices**.
>
> The main goal is applying concepts such as:
> - 3-Tier Architecture
> - ADO.NET data access
> - CRUD operations
> - Business layer design
> - UI modularization with UserControls
> - Filtering and paging concepts


## 🛠️ Technology Stack

- **Language**: C# 7.3
- **Framework**: .NET Framework 4.8
- **UI**: Windows Forms (WinForms), Guna UI2
- **Database**: SQL Server
- **Data Access**: ADO.NET (including text queries and some stored procedure usage in parts of the project)

## 🚀 Getting Started

### Prerequisites
- Visual Studio 2019/2022/2026
- SQL Server
- .NET Framework 4.8 targeting pack

### Installation
1. Clone the repository.
2. Run the provided database script (with sample data).
3. Update connection string in `App.config`.
4. Build and run the solution.


**Sawa Store** is a desktop WinForms demo project that simulates core e-commerce/admin operations to practice software development concepts.
